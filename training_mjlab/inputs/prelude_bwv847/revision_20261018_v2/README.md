## 证据范围

来源为最新已完成的 `exper009`（Slurm 3670，25,000,448 transitions），best 位于 vector_step 47000。使用 best 的三次评估物理事件，以及导出作业 4104 的同一次 200Hz 回放。已检查 config、best.pt、物理子步记录 SHA；对比数组逐项等于真实琴键 qpos 按模型阈值重建的激活状态，谱事件与 checkpoint 内嵌原谱一致。

**该轮实际训练 yaw=0.15rad（约8.59°），Pitch 为 [-0.16,0.16]，四指 MCP 上限1.2rad；不是 yaw=30°/新范围的测试。** 本版依据旧训练暴露的问题修改指法，尚无新范围下的重新训练或动态成功率。此前八指60°耦合角可达测试不构成真实按键证据。

按住比例定义：原谱音符持续区间内，琴键实际激活的200Hz样本数 / 区间总样本数；表内对同音高、同分配手指的多次音符取平均。它与150ms起音匹配率不同，也不证明是指定手指触键，更不能把漏按直接归因为物理不可达。三次评估用所有匹配事件及 extra 事件重建实际激活，迟到但保持的音不会因起音匹配失败被误算为全程未按。

## 本次改法

采用保守的同手动态规划。冻结回放或三次评估平均按住比例达到65%的音符；困难音的替代手指至少有3个同音高样本，或相距最多4半音且同黑/白键类别的样本。替代均值至少65%，再扣除同音高10%、邻近音高20%的不确定性折扣，仍须比原分配好12个百分点才能入选。整句联合权衡同指占用、跨指、快速同指跳跃和手位连续性。手位代价沿用原候选生成器的启发式音高偏移，不是硬件标定或IK。

最终61处中，例如：

- 右手7处 D♯4：拇指→食指。
- 右手2处 G♯4、2处 D♯4、2处 F♯4：小指→中指。
- 右手2处 G4、2处 F4：小指→无名指。
- 左手4处 G♯3：拇指→食指；2处 D♯3：小指→中指。

只调整清单内的具体音符位置，**不是整曲相同琴键统一换指**。`changes.csv` 给出零基 note_index、谱时间、旧/新 finger_id、标准指号和替代依据。finger_id 0–4=右拇/食/中/无名/小，5–9=左拇/食/中/无名/小；标准指号1–5在每手分别计数。

- 除 NoteSequence.part 外，整个protobuf所有字段与原谱完全相同；音高、起止时间、力度、轨道、踏板及元数据未变，左右手归属未变。
- 原始连续时间、20Hz、40Hz均无同指同时分配不同琴键冲突；项目实际 strict_v1 解析器检查通过，分别1581/3161帧。
- 3项离线单元测试通过：谱数据不变/冲突拒绝、迟到未匹配事件仍计入按住比例、拒绝稀疏替代依据。
- 仍困难而未调整的音符见 `unresolved_notes.csv`；未调整可能因为替代证据不足或连续性约束。不是已证明不可达，也不是已解决。右小指 D♯5、D5、左小指 G♯2/A♯2、两处C2长音等仍需当前模型的动态验证。
- **新指法只完成离线结构验收，未测量性能提升，未启动训练。** 现有 checkpoint/config 不变。后续新训练显式传活动 proto 的绝对路径；不能继续使用原 checkpoint 内嵌旧指法来验证新版本，固定归档里的旧谱也不会自动改变。
