# A3.2 全曲重复音型候选 · 2026-10-25

这是整首《土耳其进行曲》的模型约束指法候选，不是已验证的可执行轨迹。本目录没有改变训练入口、模型自由度、奖励点或原谱时间。

覆盖全部 2544 音（右 1460、左 1084），原始末音结束于 222.47395833333334 秒。原 MIDI 为 480 ticks/四分音符、120 BPM；0–0.5 秒为 1/4 弱起，其后为 2/4，共 223 个含弱起小节。所有 note 的非 `part` 字段与全部 NoteSequence 元数据均逐字段等于原 MIDI 导入结果；不是控制网格量化后的谱。

## 这个候选依据什么

依据当前 A3.2 独立左右 URDF 的真实关节链、末节支撑点和指长关系、四指 MCP/SW 与 10–80° 末节耦合、实际动作上下限及共享腕部采样。没有采用人手指法模型的输出。几何来自本研究固定的 exper038 冻结源码和编译场景；并行任务对新默认归档的修改不被本研究覆盖。腕 Tx 轴为 world +Y，Ty 轴为 world −X；本候选仍结构性移除 TZ/Yaw，Pitch 保持 0–0.5 rad，没有因新范围探索扩大默认自由度。

DP 的一般可达性代价使用原任务固定指尖/琴键目标的有限采样代理，并不等于真实键顶接触。另保留已经用当前模型真实有限顶面、正确接触法向及耦合静态检验过的两种一拇四和弦分配：右手 73/76/81/85→0/1/3/4，左手 45/49/52/57→9/8/6/5。七次出现共 28 音固定，邻音由全曲 DP 重排；静态接触成功没有被当作负载按键或动态成功。

## 全曲重复审计与选择

按原 MIDI ticks 对 1、2、4 小节窗口比较音高、起音、结束时间，并纳入跨小节持键。发现 468 组严格重复，覆盖 2379/2544 音（93.51%）；窗口互有重叠，组数不能相加当作独立乐句数。另有 6 组严格移调及 20 对小幅音高改写模式；这些只作审计，没有照抄指法。速度/力度仍原样保留，但力度不参与指法模式签名。

最终统一了 6 组经全曲持键与自然指序检查的重复模板。对几何退化的模板和八度高发模板解除硬统一，以免为形式一致牺牲可达性。388 条固定 note→finger 约束包括原 28 条四和弦、选定重复模板及 8 个起音的基线几何保护；未约束的邻音由全曲 DP 优化。全曲重复组中指法不一致数 69→67，单手视图仍为 37；没有声称所有重复都已统一。

最终参数为 thumb penalty=100、exchange weight=1000、recovery preference=0.05s；其他几何/移动参数不变。中间版虽然可降至 142 次短复用，但左手 8 个起音的选中残差从约 2.7mm 升至 10.4–10.6mm，因此被拒绝。最终候选没有新增选中残差由 ≤10mm 跨越到 >10mm 的起音。

剩余短复用主要是右手 48.5–64.5 秒和 112.5–128.5 秒连续八度的唯一拇指低音。五种单小节重复模式包含原 165 次中的 104 次。宽和弦边界仍有约 1.042ms 的同小指 C#6 重击，以及 13.542/26.042ms 的邻音换键；保留在审计中。50ms 是软偏好而非硬件标定值，不能以长按覆盖下一次起音来宣称重击成功。
