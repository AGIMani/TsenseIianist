完整 bank 对本候选全部 1357 原始起音、348 个双手指键组合重新进行耦合、原生接触及有限键面/法向检查。相同组合只缓存候选姿态，每次出现重验；按下琴键最大角只写入独立 scratch 状态，物理积分步数为零。最终保留全部 989 个基线成功起音，另有 21 个成功：其中 14 个组合指派不变、属于搜索/缓存见证恢复，7 个涉及指派变化；不能将 +21 全部归因于指法。仍有 347 个起音无严格静态成功见证，有限搜索失败不等于不可达证明。静态复用不代表进入/释放路径、受力、重击或连续演奏成功。
