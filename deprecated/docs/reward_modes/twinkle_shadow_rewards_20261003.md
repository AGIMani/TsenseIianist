## 提前松键：实测结论

**音符仍有效时，提前松键本身不会提高按键奖励；但晚松后的错键损失可能大于补足音尾的收益，真实动作对照中多按一帧确实经常降低后续回报。** 这支持“提前释放以避免晚松代价”的解释，但不是所有提前松键都最优，也不能据此认定附加惩罚是唯一原因。

诊断对象为原R6 best（`R6_false010-20261003-032316-404924/best.pt`，SHA `89298e075f9086d58415bfb5a2c485d196673f70aca717e613b34802be03ce09`），按它自己的旧奖励和固定原归档`logs/hpc/twinkle_f1_20261003/source_v1.tar.gz`运行，不用新五项配置给旧策略重评分。原十回合的1426个漏采样中，720个为音尾提前释放、496个迟触、210个整音遗漏；这是现象分解，不是奖励因果证明。

Slurm **1515** 于17:44前完成，72秒、exit 0:0。单次完整诊断轨迹400Hz精确F1=.984520，TP/FP/FN=5088/18/142。6个音×3个临近结束状态，共18个分支起点；每个起点比较原策略、原策略重复、该指保持旧按压目标一帧/至音符结束、整手保持至结束。每支向前6个控制周期（150ms），后续恢复闭环策略。

18/18状态复原、54/54干预比较通过。各分支动作前qpos/qvel/谱面索引/完整观测逐值一致；无干预重复轨迹最大qpos差6.71e-7、单步奖励差1.19e-7，逐步全部TP/FP/FN和目标键激活bit一致。1506首版诊断使用过严1e-7重复容差而拒绝，原输出保留；v2仍要求起点完全一致，重复轨迹容差改1e-5并要求实际离散评分一致、报告噪声与效应差值，不将首版失败当作有效对照。

### 1. 固定其余状态：补齐音尾只会增加奖励

在实际轨迹中，仅把仍属于目标的74个尾部漏采样补为该键最后真实按住时的行程/激活，其余奖励项不动。33个受影响控制帧合计奖励**增加0.476830**，没有负增益帧，false_press变化0；重算按键奖励与GPU记录最大误差5.96e-8。因此没有发现“音符还应按住，但奖励公式反而偏爱抬起”的直接错误。该评分反事实不是已经实现的可执行控制策略。

### 2. 真实继续按压：收益可能被晚松代价抵消

第18个音D4/L1（数组index17），时间从回合reset开始、含1秒准备。在各自的相同物理起点延长该指旧按压目标25ms，再让策略接管：

| 干预起点 | 补回目标采样 | 新增错采样 | 原策略150ms总奖励 | 干预后总奖励 | 差值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 5.700s | 3 | 0 | 8.608460 | 8.622831 | +.014371 |
| 5.725s | 7 | 5 | 8.622203 | 8.522823 | −.099380 |

第二行当前25ms的奖励实际**1.286383→1.310901**，目标采样覆盖5→10；随后多出5个晚松错采样（12.5ms），令150ms合计回报下降。按原gamma=.75折扣后也下降.068372。具体分项如下，均为6步合计的“继续按压−原策略”：

| 奖励项 | 变化 |
| --- | ---: |
| 按键 | −.084847 |
| 能耗 | −.010041 |
| 指法 | −.002528 |
| 新增false_press | −.004977 |
| 闲指姿态 | +.003014 |
| 踏板／碰撞 | 0 |

主要损失来自原按键项内的错键代价，新增false_press只占小部分。54项干预中39项确实补回目标采样，其中34项后续总奖励降低、5项提高；这些是同一轨迹的相关局部干预，不是54次独立训练。第一行也明确显示策略仍有可改善的释放时机，不能说提前松键已全局最优。

### 3. 原奖励为什么也会出现这一取舍

原Shadow按键分的一半奖励目标键行程平均，另一半奖励“没有任何错键”。多键同时弹奏时，漏掉一个目标键只损失目标均值的一部分；音符结束后仍激活的一个键，却足以丢掉完整的无错键项。当结束点落入25ms控制窗口，而手指/琴键还有响应过程时，继续按压可能补到较少目标采样、造成更多晚松采样。当前R6的子步聚合会真实累积这种取舍。

用原R6函数及真实目标时间做理想行程对照：D4结束所在5.750–5.775s窗仅2/10采样仍为目标，整窗按住的按键+false分=.294000，整窗释放=.483335；其中原按键项差+.183335，额外false差+.006。前一个完整目标窗则按住更高。其他音也有按住更高的结束窗，不能仅凭结束点未对齐归纳全部提前释放；40Hz网格对齐的音也有早松。

因此，**关闭附加奖励不会自动消除原按键分中“漏一键与晚松错键”的不对称**。本轮五项从头训练会检验实际表现，400Hz精确F1继续独立衡量；新末端评分可能漏掉控制周期内瞬态，不能用更高总奖替代F1改善。gamma、能耗、姿态、指法切换各自对训练结果的因果贡献尚未做独立消融，不将本次有限窗口结果扩大为长期证明，也不直接把“保持旧目标”写成控制修复。
