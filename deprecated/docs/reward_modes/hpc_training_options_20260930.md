## 当前闲指奖励的分值与开关（2026-10-01）

双卡入口使用 `coupled_40hz_idle_posture_20261001.json`。

外部weight是分项的乘数，不是概率，无需总和为1。weight=1表示原分值直接生效；原分值的范围也决定相对强度。新配置的8个启用项weight均为1。总奖励仍为各分项最终贡献相加；强行把权重归一化会缩小奖励，同时改变其相对SAC熵项的尺度。

令每根手指四个实际关节相对原始参考姿态的均方角度误差为`mse`，新姿态项为：

```text
最终姿态扣分 = -0.01 × Σ闲指 [mse / (mse + 0.25²)]
```

当前用指与0.15秒内即将用指不计姿态罚；分母始终为十指，不随闲指数变化。参考姿态仍来自场景origin，PIP/DIP即使作为从动关节也按实际角度计偏差。准备/休止也计算，不以弹对全部音为前提；移除几何风险和几何参考可行性掩码。十根闲指RMS偏差均为0.25rad时最终扣0.05，零偏差为0，极大偏差趋近总扣0.1。

该上限是用户选择的**每控制步**单位，40Hz时一秒最多累计扣4；改变频率会改变其每秒强度。其余项仍按dt/.05换算：跨掌原始-0.5变为最终-0.25，同手原始每对-1变为最终-0.5。按键、踏板、能耗、错键下压及指法公式保持；当前指法优先已关闭并在新JSON显式记录，当前与未来用指共同平均，不再乘`(1-current)`抑制未来项。

跨掌由原+0.25/0变为0/-0.25，每步整体减去0.25。因此总return会下降，不能据此认定F1退步。旧JSON、旧几何gesture模式及旧优先公式保留用于既有检查点合同；新合同不能静默恢复旧奖励检查点。

### 分阶段指法

`--staged-fingering-reward`仍为可选，当前默认关闭。开启后，当前指定手指的原始指法分由30%接近分和70%实际按压分组成：后者同时看XY对齐、指尖接近真实键面及实际琴键行程。零键程时当前手指最多0.3；这是几何/键程评分，不等同真实接触力检测。未来定位仍单独参与同一指法预算，最终该项仍有时间缩放。

### 提前请求目标许可

`--upcoming-press-permission-time .05`用于旧几何模式：在未来音开始前50ms内，对符合目标键位置/深度条件的即将用指请求目标，放宽末节接近/按压的几何罚；真实几何风险、近端、其他键和键底约束仍保留。它不会自动提前动作、移动MIDI起止或保证触键。闲指姿态方案已移除几何评分，开启该许可会明确报错；当前默认许可为0，若测试该许可，须显式切换到geometry_clearance_v1奖励配置。

原物理碰撞、几何诊断及best键底门槛保持；移除几何奖励不等于移除这些机制，也不代表已验证无穿透。原8项启用奖励中本次只改变上述掌部、自碰撞、姿态项，长期F1和碰撞改善待新训练验证。

该奖励实现此前CPU验证：65项测试及71项参数子测试通过，覆盖新分值、当前/未来豁免、固定十指分母、dt例外、旧奖励与检查点合同、入口配置和独立时序开关。GPU集成测试的预期和式已同步，但本次未执行GPU验收或训练。

## 奖励定义与历史

2026-10-06新增H100实验按提交时实际根脚本执行：`--joint-motion-full-penalty-excess 0.1`，超限5%扣2.5、10%扣满5。以下0.2是通用默认和先前实现验收值，不能覆盖当前CLI；参数捕获和最终运行证据位于`logs/hpc/h100_motion_experiment_20261006/`。其余软阈值及腕硬目标限制保持。

使用最终实际下发的完整物理目标 `q_t`，包含动作映射、限速、耦合、几何保护及最终限制后的结果；不是31维原始策略输出，也不是实际qvel/qacc。每个控制步：

```text
v_t = (q_t - q_(t-1)) / control_dt
a_t = (q_t - 2*q_(t-1) + q_(t-2)) / control_dt²
e = max(0, 所有关节 abs(v_t)/所属组速度阈值 - 1,
           所有关节 abs(a_t)/所属组加速度阈值 - 1)
reward = -maximum_penalty_per_step * min(e/full_penalty_excess, 1) * weight
```

默认 `full_penalty_excess=.2`、`maximum_penalty_per_step=5`、`weight=1`。不超限0，最大相对超限10%扣2.5，达到20%扣5；所有关节、速度和加速度只取最大超限比例，整项不逐关节叠加。该项使用每控制步单位，不再乘全局dt缩放；校验weight≤1、最大罚值≤5。腕硬上限比惩罚阈值高4.72%，因此仅腕部达到硬上限时约扣1.18；手指仍可能触发完整−5。

当前control_dt=.05s：手指10rad/s对应相邻目标差.5rad；腕硬速度对应相邻目标差≤.15708rad，硬加速度对应连续两次目标差的变化≤.03927rad。200Hz物理子步不作为上述差分时间间隔，未增加动作插值或改变控制频率。

reset将前两次奖励目标置为实际reset下发目标，初始命令速度按0处理；第一控制步和策略准备段照常计罚，局部reset只重置指定环境。旧配置缺少新项时补为关闭，旧项数值不变；奖励或硬控制合同变化继续触发checkpoint不兼容，旧模型回放仍用匹配归档。新增加速度依赖前两次下发目标，当前观察维度不变，不能称新增项消除了历史依赖。
