## 3. 提前定位不再稀释当前指法

旧公式当前与未来用指共享分母，本曲 45 个有音帧出现这种情况，当前份额最低为 1/3。

新增 `--anticipatory-current-priority`，`run.sh` 显式开启，旧 JSON 缺字段保持旧公式。设当前指法均值为 C、原未来定位均值为 F（F≤.5）：

```text
有当前用指：C + (1-C) × .2 × F
无当前用指：F
```

总指法分仍≤1；当前贡献不会因增加未来手指而下降，对 C 的影响系数≥.9。取舍：C=1 时未来定位不再额外加分；准备／空谱时仍有≤.5 的未来定位信号。未额外增加 humanoid 惩罚或指法总权重。

`run.sh` 的提前秒数仍为 0；`run_tsensei_a32.sh` 保持 .15 秒。新优先开关只有提前定位启用时有作用。两项开关、现有分阶段指法、正确键子步均值和激活权重均独立保存，不自动改变旧检查点。
