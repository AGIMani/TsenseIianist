# 关节硬限位与轨迹导出（2026-10-05）

用户要求：仿真中下限为零的 PIP/DIP 不得出现负角度；机器人每个关节的导出位置须在 URDF 或显式规定的范围内，并核查策略输出。

## 实现合同

统一入口 `all_use_this_train.sh` 开启 `--hard-joint-limits`，保存为 `control_limits.joint_state_limits=hard_v1`。实际每个关节的范围及 qpos/dof 地址保存在 `control_limits_contract.joint_state_contract`，参与原有 checkpoint 控制合同校验。缺少此字段的历史配置仍使用原行为；不能直接把旧 checkpoint 当作采用新动力学的结果。

每个物理子步积分结束后，对模型中有限位的机器人 hinge/slide 关节执行位置投影；有效范围取编译模型、物理动作范围与显式位置限制的交集。关节在边界仍朝外运动时，其速度清零，受影响自由度的求解器 warmstart 清零。随后刷新几何／接触，再采集子步奖励、录音按键和状态。CUDA 图、普通步进与回放 callback 共用同一处理。reset 仅处理指定环境，保持其他世界状态；移除的腕轴不会重建。钢琴琴键不属于机器人关节，不改变琴键动力学。

float32 上下限向区间内部舍入，避免十进制上限转换后略微超界；最终物理驱动目标也执行相同范围约束。此约束改变动力学，属于非弹性状态投影，不等同于标定过的实体限位接触力，不保证能量、接触力或实际速度／加速度满足硬件限制。每环境／关节累计修正次数可由 `joint_limit_corrections_since_reset` 查询。

这是一项位置限位功能。合法的负 swing、腕部、机械臂角度仍然允许；负速度／加速度也不等同于负位置越界。原 URDF effort/velocity=0 仍待标定，未编造手指速度或加速度限值。
