## 映射公式

每个动作通道独立保存 `policy_min`、`policy_max`、`physical_min`、`physical_max`。令策略动作是 `a`：

```text
t = (a - policy_min) / (policy_max - policy_min)
q_target = physical_min + t * (physical_max - physical_min)
```

因此当前 8 个四指 MCP 均为 `q_target = 0.6 × a`：`a=0 → 0 rad`、`a=1 → 0.6 rad`、`a=2 → 1.2 rad`。Actor 的 tanh 输出按每通道上下限做仿射变换；随机预热、replay 范围检查、GPU 场景和手动预览使用同一合同。当前每个策略区间宽度仍为 2，所以仿射尺度为 1，不额外改变 SAC log-prob；实现仍包含通用尺度 Jacobian，避免未来修改区间宽度时漏算。
