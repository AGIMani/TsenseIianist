# 三组四指耦合 F1 分析

2026-09-30。比较 Slurm 1077/1078/1079。三组均为 seed 42、512 环境、
3,000,320 样本、726,656 次 SAC 更新，TX/TY 1 m/s、提前定位 0.15 秒，
奖励、模型、时序、学习率和评估频率一致。三组完整预算和配置合同均通过。

## 结论

本次单种子结果支持“四指耦合，但保留完整物理观测”。它在 best、final、
末 50 万样本和 200 Hz 指标上都优于基线和压缩观测组。相对基线，best 音乐
F1 提高 3.90 个百分点，final 提高 4.44 个百分点；best 的 20 Hz 漏键帧由
59 降至 43。

删除从动 PIP/DIP 的实际位置和上一动作观测没有继续改善效果。压缩组相对
完整观测组，best 低 1.09 个百分点，末 50 万均值低 1.91 个百分点。PIP/DIP
虽然由控制器给目标，实际状态仍受伺服滞后和接触影响，因此这些观测不是无损冗余量。

耦合的代价是物理接触质量退化。final 的手部碰撞子步从基线每回合 10.67
增至完整观测 79.0、压缩观测 116.33。三组键底接触均为 0，但耦合组的键侧、
非末节接触更多。当前不能把 F1 提升解释为整体动作质量提升。

## 等预算结果

| 组别 | 动作/观测 | best 步 | best F1 均值/最低 | final F1 | final 200 Hz F1 | 末 50 万 F1 均值 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 基线 | 47/1231 | 5800 | 0.89212 / 0.89072 | 0.88397 | 0.86949 | 0.88144 |
| 耦合、完整观测 | 31/1231 | 4200 | **0.93115 / 0.92975** | **0.92841** | **0.91516** | **0.91834** |
| 耦合、压缩观测 | 31/1199 | 5600 | 0.92024 / 0.91908 | 0.91569 | 0.89993 | 0.89928 |

完整观测耦合相对基线：best +3.90、final +4.44、final 200 Hz +4.57、
末 50 万均值 +3.69 个百分点。压缩观测相对基线仍有提升，但相对完整观测：
best -1.09、final -1.27、final 200 Hz -1.52、末 50 万均值 -1.91 个百分点。

完整观测组约 2.15M 样本时已取得 best，后段大多稳定在 0.917～0.930；
基线和压缩组的 best 分别到 2.97M、2.87M 才出现。完整观测组末段曾有一次
0.8497 的短暂回落，所以这里只把它视为本种子的明显优胜，不把单次训练当作
跨种子确定结论。

## 漏键与误键

best 三回合平均：

| 组别 | 20 Hz TP / FP / FN | 200 Hz TP / FP / FN | 音乐段错键子步 |
| --- | ---: | ---: | ---: |
| 基线 | 236.0 / 0.33 / 59.0 | 2305.0 / 13.0 / 645.0 | 12.33 |
| 耦合、完整观测 | **252.0 / 0 / 43.0** | **2451.3 / 22.7 / 498.7** | 22.67 |
| 耦合、压缩观测 | 247.0 / 0.33 / 48.0 | 2428.3 / 18.3 / 521.7 | 18.33 |

完整观测耦合比基线多命中约 16 个 20 Hz 目标键帧，少漏约 16 个；200 Hz
也少漏约 146 个目标键采样。它的 best 同时增加了短暂错键，并在释放尾段有
35 个错键子步。训练 final 已把音乐错键降至 8、释放尾段降至 2.67，200 Hz
F1 反而由 best 的 0.90388 提高到 0.91516。

因此若现在选择一个可回放候选，建议先用 1078 的 `final.pt`：它的 20 Hz
F1 只比该组 best 低 0.27 个百分点，但 200 Hz 时序、尾段释放和碰撞都更好。
基线和压缩组则仍是各自 `best.pt` 更合适。

## 碰撞和 60°约束

| 组别/检查点 | 手碰撞子步 | 同手 | 跨手 | 键底 | 当前用指实际角误差均值/最大 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 基线 best | 7.0 | 0 | 7.0 | 0 | — |
| 完整观测 best | 122.0 | 14.67 | 107.33 | 0 | 12.68° / 28.09° |
| 完整观测 final | 79.0 | 0 | 79.0 | 0 | 12.70° / 29.25° |
| 压缩观测 best | 40.33 | 0 | 40.33 | 0 | 12.86° / 25.94° |
| 压缩观测 final | 116.33 | 51.0 | 65.33 | 0 | 13.06° / 29.14° |

求解器的目标误差约 0.0001°，不可达比例为 0；但实际当前用指误差约
12～13°。这说明从动目标在几何上可解，物理执行受驱动滞后、接触和整手运动
影响较大。角度诊断采样于 20 Hz 控制周期末，`active` 是当前谱面用指，并非
200 Hz 实际触键瞬间，不能声称每次击键都保持 60°。

## 采用建议

1. 保留 `--finger-coupling`，关闭观测压缩，即 31 动作/1231 观测，作为下一轮候选。
2. 不把 31/1199 设为默认；本轮没有显示降维收益，训练墙钟也没有缩短：三组均约 35 分钟。
3. 下一步先处理耦合后的跨手碰撞，再做至少两个新增种子。修复时保持奖励和耦合角度不变，避免再引入多因素混杂。
4. 复核 1078 final 的逐音漏弹、提前松键和 200 Hz 真实接触角。如果碰撞修复不损失 F1，再做完整 5M 验证。
