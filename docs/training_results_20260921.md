# 2026-09-21 训练结果与 F1 曲线

## 结论

截至本次检查，V3.2 的 6 轮正式 MJLab 训练中，5 轮完成，1 轮因用户切换曲目而主动停止；未发现仍在运行的训练进程。另扫描到 12 个 MJLab 短测试目录及 2 个历史 JAX 训练目录，全部列入机器可读清单。

**小星星已有较高 F1；两轮《月光》完成了采样预算，但演奏指标没有改善，最终 F1 都低于首次评估。** 当前 mixed_v1 训练不能视为演奏成功。

## 《月光》为什么需要关注

![月光 F1 与召回率放大](../preview/outputs/training_reports/20260921_f1/clair_detail.png)

| 评估指标 | legacy 首次→最终 | mixed_v1 首次→最终 |
| --- | --- | --- |
| 逐帧平均 F1 | 0.110728 → 0.022305 | 0.093584 → 0.011787 |
| 逐帧平均 Recall | 0.083514 → 0.018754 | 0.072787 → 0.011596 |
| 最终 micro-F1 | 0.024615 | 0.015320 |
| 整曲回报 | 4393.408 → 4256.804 | 3717.116 → 2911.141 |

实测说明最终策略漏掉了绝大部分目标按键，且 F1 的下降不是单纯由两种归约口径造成。首个评估都只有 32 次梯度更新；后续训练没有超过这一初期水平。最终逐帧平均 Precision 虽为 0.7968／0.7460，但当前 `binary_metrics` 在一帧没有任何预测按键时把该帧 Precision 定为 1，因此不能只看这个平均值认为策略已准确演奏。

日志中正式训练的 `train` 标量未发现 NaN／Inf，5 轮都有 completed 摘要及最终评估，故没有观察到训练进程崩溃或指标非有限值。但这不证明物理无异常，也不证明学习过程正确或已收敛。

本曲一次整曲评估 2587 帧（约64.675秒），新物理小星星为315帧（约7.875秒）。同样5M采样，两轮月光各完成1792个训练回合。更长曲目、双手配合和候选指法可达性是需要排查的因素；**当前曲线不能证明下降由自碰撞、动作映射、奖励权重中的哪一个单独造成**。两轮月光还同时改变了动作坐标与Pitch范围，且只有一个seed，不能当成严格单变量实验。

建议下一步先对两轮月光的 step-1000 与 final 做同场景回放，检查实际按键／目标／指尖距离／碰撞及分项奖励，再判断是候选指法不可达、按键收益与其他奖励竞争，还是动作与姿态限制。TODO(V32-TRAIN-01)：月光F1退化的根因尚未定位；本次只整理证据，没有自行修改奖励、指法、课程或训练参数。2026-09-28已取消仅因设计与论文重合而产生的对齐确认流程。V32-SCORE-02（候选指法可达性）、V32-SAC-03（跨次物理轨迹差异）与V32-06（接触标定）继续保留。
