# V3.2 末节定位点测量

## 方法与限制

读取本包规范 URDF 的 collision STL，经 scale/origin 变换到末节连杆系；取局部 +Z 最大顶点集合的包围盒中点。该点是暂定奖励定位点，不是已标定的真实指垫中心（TODO V32-07）。

当前测量输入为 `A3.1V6 26.8.4-2.urdf` 及其配套网格。独立检查 MuJoCo 编译后的网格，确认定位点处于凸包内且具有最大局部 Z；临时右手相应点为镜像。
