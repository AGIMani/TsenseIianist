# 黑键梯形实体与钢琴原点（2026-10-23）

按本轮用户要求，36个黑键统一使用上表面10×90 mm、底面12×95 mm、高18 mm的凸多面体。琴顶端指远离演奏者的后端（局部−X端）：上下表面在此齐平，底面仅向演奏者（+X）延长5 mm。横向Y中心线、原键体/关节基准及上表面中心的X位置不变；底面中心和体积形心因非对称延长而自然偏移，不能同时要求它们也不变。此前上下居中、两端各伸2.5 mm的示意已被本轮要求替代。

| 当前几何 | 钢琴局部坐标（mm） |
|---|---|
| 钢琴原点O | (0, 0, 0)，52白键总横向中心、白键前后中点、白键底面所在平面 |
| 轴向 | +X朝演奏者/键前端，+Y朝高音，+Z朝上 |

黑键接触和外观共用一个8顶点、12三角面的凸mesh，没有长方体碰撞代理。MuJoCo会把mesh转换到其内部主轴，编译后的`geom_pos/geom_quat/geom_size`因此不能直接当作琴键中心、XYZ半尺寸或顶面。现有每键隐形reference site保留原键体中心、90 mm上表面长度和18 mm高度，宽度设为上表面10 mm；它没有实体接触。Composer、CPU导出、GPU逐子步采样和指法编辑读取这个site，白40/黑20 mm的指法目标及0.5半高Z偏移公式和数值保持，避免新mesh内部坐标暗中改变奖励。指法几何manifest明确记录`key_body_upper_surface_site_v1`，旧几何合同不静默迁移。

质量0.02 kg、此前显式冻结的惯量/惯性中心、90 mm名义铰链力臂、弹簧、阻尼、armature和100%激活保持；2026-10-23后续将白/黑键标称行程改为12/10 mm，关节上限分别为atan(12/150)和atan(10/90) rad；这不是按新形状均匀密度重算质量模型，也不是硬件标定。诊断杠杆读取reference site。可选几何保护读取site顶面和平面法向，黑键XY外包范围覆盖12×95 mm底面，属于保守平面近似；当前统一入口仍关闭其物理投影。实际激活/指法着色直接着色mesh表面，不用主轴包围盒遮住斜面。
