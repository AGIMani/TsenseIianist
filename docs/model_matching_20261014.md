# A3.2 新模型指尖／耦合匹配修复（2026-10-14）

本轮修复新导入 A3.2 的指尖定位与四指 60°～80°从动控制之间的坐标假设失配。URDF、STL、凸包、质量惯量、关节限位、安装和初始关节角保持原值；随后按用户先前要求将积分器改为 Euler。重训因此同时包含定位修复和积分器变更，不能视为单一积分器对照。

## 问题与修复

旧 `measure_distal_tip` 固定选择末节网格的局部 +Z 极值。当前 CAD 的末节铰链轴是左 +Z／右 −Z，+Z 极值落在轴承附近侧壳；测量方向与 DIP 轴夹角只有约36°～37°。这使耦合控制及指法距离奖励使用了错误的末端几何定位点。

当前只采用 `urdf_chain_distal_support_v1`：

1. 从 URDF 相邻两个铰链中心的位移求手指朝外方向，并变换到末节 link 坐标系。
2. 去除沿末节转轴的轴向安装偏移，得到指节延伸方向；不硬编码局部 X/Y/Z，也不改变关节旋转轴。
3. 对经过 URDF mesh scale/origin 变换的碰撞凸包，取该方向的最远支撑面／边中心作为指尖。面中心按凸多边形面积计算，边用两端中点，单点直接使用；不受内部细分顶点数量影响。
4. 两手十个指尖统一更新。八根非拇指仍用 DIP 中心指向该指尖计算向下角；拇指控制方式不变，但其指法距离定位同步修正。

这延续已确认的“末节沿指尖方向相对琴面向下”的定义。仍为几何定位，TODO(V32-07)：不是实测指垫中心、表面法向或材料变形标定。禁止将其宣称为硬件触键角保证。
