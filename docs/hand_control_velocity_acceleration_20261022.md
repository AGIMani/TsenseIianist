## 计算方法

### 下发关节目标

取 `downlink.sent=true` 的 `sdk_targets.applied_pose`，关节角单位为rad；通过 `command_id` 与 `h7.control_dt_s` 对齐。设第 i 条指令为 qᵢ，对应控制周期为 Δtᵢ，则：

```text
vᵢ = (qᵢ − qᵢ₋₁) / Δtᵢ
aᵢ = (vᵢ − vᵢ₋₁) / ((Δtᵢ + Δtᵢ₋₁) / 2)
```

速度与加速度取绝对值峰值。该口径衡量控制周期上的目标变化率，不代表电机收到每条指令的精确时刻，也不代表实际关节角速度。日志的下发成功语义是SDK发送调用成功返回，并非固件执行确认。

### 实际电机反馈

取已接受的 `telemetry` 中有效且在线的电机测量，使用设备 `tick_ms` 时间轴。直线电机使用已规范化符号的 `pos_act_mm`，旋转电机使用以deg表示的 `position`。

设备时间通常以10ms递增。遇到非10ms间隔时切开数据段，不跨缺测间隔求导。每个连续段使用7点、3阶 Savitzky–Golay 局部多项式拟合，点间隔10ms，窗口首尾跨度60ms；分别求一阶、二阶导数，并排除段首尾各3点。

反馈结果是降噪后的运动估计值，拟合会改变短时峰值。尤其加速度对量化、噪声和采样非常敏感，不能将其当作连续时间的精确最大值。日志记录的是主机采集到的SDK最新状态快照，不是每一份总线数据包。
