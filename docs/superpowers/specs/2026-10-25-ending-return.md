# 曲尾物理回程
用户确认目标是准备段开始前的原始初始姿态。完整演奏在原谱及已有松键尾段结束后，从实际末帧继续物理积分：腕保持末帧目标，手指平滑松回原始参考，然后双手平滑回原始参考并稳定。初始 qpos/qvel/ctrl/暖启动保持，后续不投影或裁剪状态，保留超限、误触及误差。回程不属于 SAC 经验或原谱评分；批量训练预算、done/reset 保持。默认入口显式 --ending-time 2，最短回程时间可因速度/加速度延长，另有松指与稳定时间。仅 first_note_v1 已验证的无臂固定 TZ/Yaw 合同可用。
视频、物理录制、实际声音、交互回放和原谱对比图同步包含结束段；原谱不延长音符，结束段目标为空。失败保留原始数据，不伪造复位或完整成功。新默认仅在远端验证、源码冻结和 SHA 更新后生效，不修改旧实验。

物理到位验收：手根平移误差≤5mm，腕角≤.01rad，实际末速度≤.1（各轴原单位），无激活琴键；原始手指参考持续作为目标，实际每轴残差全部报告，>.05rad警告。原始reset参考不一定为接触平衡，不能宣称逐关节数值完全相同。
