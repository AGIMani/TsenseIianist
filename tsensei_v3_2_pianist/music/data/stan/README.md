# Stan 1 曲目与指法

当前注册名为 `Stan1`，训练环境为 `RoboPianist-debug-Stan1-v0`，入口是 `robopianist-rl/run_daxian_v2_stan1.sh`。

2026-09-10 按用户要求保留原始 `Stan_1.mid` 时间轴，将用户确认可用的曲库指法迁移后注册。原 MIDI 文件保持原始字节，SHA-256：`8c9b4ff7b51f02fc4fd4ed10ce594389e8fea8e6614928f58b4017de7e50e335`。原谱 138 个音符、首音约 3.243244 秒、最后音符结束约 30.000134 秒；tempo、音符起止、力度、声部和踏板等均从原 MIDI 读取。

`stan_1_fingering.json` 保存完整音符 ID → 指法映射、原谱摘要、原 MIDI 校验值和迁移来源。2026-09-10 按用户要求从 JSON 按音符身份提取全部 138 个指法，在 `library.stan_one()` 中保存为 `FINGERING` 列表；与 `nocturne_rousseau()` 相同，按 `(start_time, pitch)` 排序后逐项写入 `note.part`。注册函数不再调用 Studio 的 JSON 应用流程，也不依赖 JSON 对象键顺序；JSON 保留为提取来源及回归比较基准，直接编辑它不会自动更新内嵌列表。保留原 MIDI 的 SHA-256 校验和音符数量检查，防止替换曲谱后错配指法。library 仅赋予指法与显示标题，不把指法写回标准 MIDI。

迁移按起音时间、音高排序核对：两谱均有 138 个音符，完整音高序列一致，均无重复的同音高/同起音事件；逐音符迁移原曲库左右手及手指编号。内部编号右手拇指至小指 0–4、左手 5–9。迁移后在 0.05 秒原生控制网格验证完整性和同指多键冲突。

训练脚本与小星星保持相同的 SAC、奖励和限速配置，使用独立 `eval_daxian_v2_stan1_<时间戳>` 输出目录。当前用户编辑的脚本开启 `--trim-silence`、`--unlock-four-finger-pip-dip` 和 `--idle-pip-dip-policy`，对应 49 维动作/2066 维观测；有目标四指的 PIP/DIP 仍由 idle-policy 分支执行 IK，空闲时由策略控制。1 秒准备缓冲保留，第一音训练目标在 1 秒；注册原 MIDI 自身的时间轴保持不变。默认 `--fingering-config current` 在注册指法之上读取 Studio 已发布覆盖，并在训练产物中记录快照。

历史实验 `eval_daxian_v2_stan1_20260910_072117` 保存的是 33/2050、保留前导静音的旧设置，第一音训练网格索引 84（4.20 秒），621 步一回合。当前文件修改不会改变该进程；不要把当前脚本值当作该实验参数。关于双手靠拢的实测和横移动作零点，见训练指南第 8.2 节。

旧的 `stan_1.json` / `stan_1_key_frames.npz` 保留作为迁移前数据：来自左右 NPY 的 `[:,7,:]`，每手 `(537,6)` 整数键号表，暂定 0.05 秒采样。旧谱约 26.85 秒，力度 80、无踏板；原始 NPY 文件摘要在旧 manifest 中。它们用于追溯和测试，当前 `library.Stan1` 不再用这个近似时间轴生成曲谱。原始 NPY 的时间/列约定记录保持历史状态，不把本次指法确认扩展为对所有原始采样元数据的确认。
